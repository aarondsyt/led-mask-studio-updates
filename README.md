# LED Mask Studio

**BETA · Android app**

LED Mask Studio connects to your LED mask over Bluetooth LE. Load and crop images, save favourite crops, and send them to your mask.

## Download

[**Download the latest APK**](https://github.com/aarondsyt/led-mask-studio-updates/releases/latest/download/LED-Mask-Studio.apk)

[View all releases](https://github.com/aarondsyt/led-mask-studio-updates/releases)

## Install

1. Download the APK on your Android phone.
2. Open the downloaded file.
3. If Android asks, allow your browser to install unknown apps.
4. Confirm installation.

The app is in beta. Android may require the same signing key to update an existing installation; do not uninstall an existing copy if you need to keep its saved images.

## App download page

A landing page is included in [index.html](./index.html). To publish it as a website, open this repository's **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
